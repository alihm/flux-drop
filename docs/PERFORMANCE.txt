Drop serving performance

Reproduce the read-only load probe:
  node scripts/serving-load.mjs https://drop.app.runonflux.io /deep-zoom/ 400 50
It warms persistent connections, discovers up to 20 Explore thumbnails and the
same-origin src/href assets of the selected site, and reports status counts and
p50/p95/p99 milliseconds. It never sends credentials or changes projects.

Instrumentation
Server-Timing reports exclusive metadata, verify and file preparation phases,
plus total Go app time through response-header commitment. For Nginx internal
redirects, Go cannot report sendfile or final transfer duration in an already
sent header. Nginx separately logs slow requests with total request_time and the
Server-Timing header. Go logs requests over one second, excluding query strings,
cookies, credentials and upload-ticket secrets. Public 503s include Retry-After.
pprof is on 127.0.0.1:6060 inside the container only, using a separate mux; no new
environment setting or public port is needed. Use docker exec/container-local
HTTP access to /debug/pprof/; never publish this socket externally.

Integrity and authorization
The integrity LRU is process-local: at most 256 versions and 32768 aggregate
stat/manifest entries. Eight cold verifications may run at once; concurrent
requests for one version share a verification. Cache hits compare the manifest,
requested file and ancestor directories' inode, size, mode and modification time.
Changes trigger a complete manifest/hash verification. This relies on published
content being immutable; undetectable bit flips with identical stat information
require a later cache miss to discover. No access decision is stored here.

Management Raft transactions use one same-term leader confirmation and final
snapshot/CAS validation. Explicit serving transactions now use coherent local
applied snapshots, with no age limit; only absent records trigger a bounded whole
leader lookup. Followers may serve old public policy/digests or old denials for an
unbounded replication delay. Known expiry is evaluated against current time.
Preview IO still validates its local snapshot after IO. No authorization decision
is cached with files. Coordinator unavailability is 503, not unrestricted leader
fallback. See CLUSTER.md for confirmation admission and rollout details.

The requested public cache lifetimes intentionally allow browser reuse after
privacy changes; these headers must not be described as instant revocation.
Private responses and pending previews remain no-store. Public file validators
come from manifest hashes, with a distinct watermark representation identity.

Explore cache lives 20 seconds with singleflight. Publish/update/claim/privacy/
rename/delete invalidate it locally; other primary instances also depend on local metadata replication, which has no maximum delay.
Public HTTP policies: thumbnail 300 seconds / stale-while-revalidate 86400;
assets 60 / 600; HTML no-cache; Explore 20 / 120; config 300 seconds.
Both Explore and thumbnails expose all response headers through wildcard CORS.
Gzip covers HTML/CSS/JS/JSON/SVG/plain text, including internal file redirects.
The shipped Nginx image has no Brotli module. Favicon returns 204 with cross-origin
resource policy. Metadata preparation keeps its ten-second budget. Local integrity and remote
fetches have separate two-minute budgets derived from the original request.

The load driver now accepts DROP_LOAD_PATHS pointing to a JSON array of paths,
so cold measurements avoid HTML/Explore discovery. DROP_LOAD_TIMEOUT_MS defaults
to 150000; DROP_LOAD_SLOW_MS pauses after chunks to emulate slow consumers.
It reports real transport-error durations, elapsed time, total/successful rps,
bytes and status counts. It is closed-loop and cannot establish maximum sustained
capacity. Never use production as an unapproved load fixture.

Serving snapshot optimization is explicit: RunSnapshot may skip final Check only
on a coherent stamped backend; legacy reads retain Check. Run/RunContent and
writes retain their original checks and durability. Immediate primary cache hits
use initial delivery authorization; each caller after shared remote fetching
performs its own post-fetch policy lookup. Preview IO retains final validation.

Runtime resource sizing
The supervisor generates /tmp/drop-nginx.conf and starts nginx with -c. Workers
use the minimum of affinity and visible cgroup CPU quota (rounded up); Go retains
its own container-aware GOMAXPROCS defaults. Nginx targets 8192 connections/worker
and upstream keepalive 64. Inherited soft/hard nofile limits are logged, never
raised by the non-root process. Low soft limits reduce worker connections with
FD headroom; limits below 256 fail startup explicitly.

When GOMEMLIMIT is supplied, preserve it. Otherwise inspect applicable visible
cgroup v2 ancestors (v1 memory/cpu fallback): drop receives 45% and drop-cluster
20% of the effective memory ceiling. A secondary/standalone app without a
coordinator receives 55%. Remaining memory is for nginx, preview children, page
cache and native allocations. Unlimited/unreadable controllers do not invent a
limit. Hidden ancestor limits cannot be inferred; soft Go limits do not guarantee
OOM avoidance, especially with Chromium. Runtime logs record chosen budgets.

Prefetch decision: omitted/disabled. No controlled foreground measurements have
yet demonstrated a benefit without contention. Foreground singleflight/cache
work is implemented independently; background slots alone would not establish
safe transport/disk priority.
