Secondary apps

Updating…

Active files are the current versions; retained versions include old and incomplete uploads. Filesystem allowance covers file blocks, directories and manifests. Temporary uploads are current reservations, not a permanent per-project reserve. Capacity is the smallest current report from healthy replicas. Available storage respects app accounting, filesystem reserves, and headroom; an unavailable app has no current availability estimate. Uploads also need temporary staging space, checked when each upload starts. Draining stops uploads and keeps existing files accessible. Removing an empty app disconnects it from this pool; Flux deployments and volumes stay intact.
